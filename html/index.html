Optimizing Burn Care Access

Optimization

A mixed-integer linear programming model that identifies hospitals to upgrade with adult and pediatric burn care. Using nationwide population and hospital data, the project minimizes population-weighted travel distance while meeting coverage targets and limiting new centers. Sensitivity analysis explores how expansion can improve access and equity, with diminishing returns after about 15 new centers.
